# ⚡ COURSE SYLLABUS: CS 301 (Advanced Operating Systems)

## 📌 1. Course Information Overview
*   **Course Code / Title:** CS 301: Advanced Operating Systems & Systems Architecture
*   **Academic Term:** Fall 2026 Academic Semester Track
*   **Prerequisites:** CS 201 (Systems Programming) AND proficiency in C/Assembly
*   **Course Delivery Platform:** Fully integrated GitHub Vault & Simulation Hub Layout

## 🎯 2. Core Curriculum Blueprint (7 Modular Pillars)
The course is engineered into 7 structural content modules tracking the complete hardware-to-software transaction handoff loop:
1.  **Module 1: Monolithic vs. Microkernel Design** -> Privilege separation structures.
2.  **Module 2: Traps & Protection Barriers** -> System calls via the Interrupt Descriptor Table (IDT).
3.  **Module 3: Concurrency & Synchronization** -> Atomic primitives, race conditions, and mutexes.
4.  **Module 4: Address Translation Mechanics** -> Page frames, MMU tracking, and TLB caches.
5.  **Module 5: Virtual Memory & Page Faults** -> Demand paging algorithms and disk swap vectors.
6.  **Module 6: Virtual File Systems (VFS)** -> ext4 inode pointer mappings and block offsets.
7.  **Module 7: Drivers & Network Security** -> Hardware interrupts (IRQ) and stateful packet firewalls.

## 📊 3. Grading Criteria & Performance Weight Matrix
Student performance evaluation is broken down into four fixed core evaluation targets:
*   **25% — Simulation Laboratory Hub Diagnostics:** Successful completion of active interaction queues across all modules (`simulation.html`).
*   **25% — Midterm Systems Examination:** Written assessment covering Modules 1 through 4.
*   **30% — Comprehensive 100-Question Final Exam:** Full-stack architecture verification matrix.
*   **20% — Capstone Group Core Kernel Driver Project:** Packaging a custom character device node module (`.ko`).

## 🗺️ 4. Semester Project Roadmap & Deadlines
*   **Week 04:** Lab 1 Checkpoint (Microkernel IPC message bus validation tracks completed).
*   **Week 08:** Midterm Examination Phase + Kernel task_struct isolation check rules live.
*   **Week 11:** Lab 2 Checkpoint (Virtual memory demand paging and disk swap faults verified).
*   **Week 14:** Capstone Driver Submission (Flushing hardware registers safely via Registered IRQ handlers).
*   **Week 15:** Grand Full-Stack Retrospective Exam Block.

## 📜 5. Strict Academic Integrity Rules
*   **Code Quality Mandate:** All memory allocations (`malloc`) must be cleanly checked and freed (`free`). Memory leaks on system infrastructure evaluation loops yield an automatic zero score flag.
*   **Collaboration Boundaries:** Students may discuss design properties using high-relatability analogies, but all technical register strings and assembly hooks must be independently compiled inside user workspace layers.
