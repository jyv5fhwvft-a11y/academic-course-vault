🎪 Delivery Options02 / 04

The Office Package Delivery Analogy

🧑‍💼 Polling: Walking down the stairs every five minutes to check an empty mailbox. Fast detection, but wastes your whole day.

🔔 Interrupt: Working smoothly until a courier rings your doorbell. You pause, handle the package, and jump back to work.

🤖 Direct Memory Access (DMA): Hiring an assistant to watch for a cargo truck, stack 100 boxes on the shelves directly, and tap you on the shoulder only when the work is completely done.

🔍 Transfer Highways03 / 04

Bypassing the Interrupt Storm

High-speed, data-heavy devices (like hard drives or network cards) streaming millions of bytes per second overwhelm a system using standard interrupts.

Enforcing DMA allows hardware controllers to read or write data blocks straight to main system RAM completely independent of the CPU, avoiding constant context-switch traps.

🛠️ Profile Sorting04 / 04

Sorting Peripheral Communication Profiles

Selecting the right interface strategy based on data density and frequency boundaries:

• Slow Temperature Sensor (1 trace/10 mins) ➔ POLLING fits. Highly predictable, no wiring overhead or interrupt line allocation required. • Human Keyboard (Infrequent, completely random) ➔ INTERRUPTS fit. Zero cycles wasted on spinlocks until a physical key matrix snaps shut. • Gigabit Network Card (Millions of bytes/sec stream) ➔ DMA mandatory. Streams data directly to a RAM buffer, firing a single interrupt only upon completion.
