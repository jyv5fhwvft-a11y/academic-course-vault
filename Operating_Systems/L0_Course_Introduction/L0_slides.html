🎯 Core Objective02 / 05

Why Does an OS Exist?

An Operating System is primarily an unyielding resource manager and hardware referee layer.

It arbitrates and shares raw hardware components (CPU cycles, RAM pages, persistent disk storage blocks) among fundamentally selfish application tasks.

🎪 Pedagogical Analogy I03 / 05

The Air Traffic Control Tower

Imagine a busy airport with 50 independent airplane pilots (User Applications) trying to land on a single runway (The CPU Core) at the exact same microsecond.

The ATC Tower doesn't fly the planes. It functions as an absolute referee, allocating runway slots sequentially so nobody collides into a system crash.

🏷️ Core Lexicon05 / 05

Fundamental Architecture Terms

🧬 Kernel: The core program of the operating system that runs with complete privilege levels (Ring 0) and stays resident in memory at all times.

📦 Abstraction: Hiding messy low-level hardware registers behind clean software interfaces (e.g., displaying raw SSD sectors as a readable file stream).
