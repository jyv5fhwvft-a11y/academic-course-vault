🎪 Power Adapters02 / 04

The Universal Power Outlet Analogy

The power grid presents a simple two-prong interface, blind to what gets plugged in. To the kernel, every peripheral presents a file container supporting open(), read(), and write().

The Device Driver acts as the adapter plugin. It catches the generic file API instructions sent by the OS and shifts them dynamically into the manufacturer's circuit register commands.

🔍 Device Core03 / 04

The Architectural Hardware Triad

The kernel divides the physical hardware layout into distinct functional sub-systems:

• Block Devices: Addressable fixed blocks, supporting random data seeks (e.g., SSDs).

• Character Devices: Continuous sequential byte streams without random seek bounds (e.g., Keyboards).

• Network Devices: Packet chunk routing layers bypassing the VFS file layer to hit sockets.
