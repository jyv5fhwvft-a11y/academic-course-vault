🎪 Sticky Notes02 / 04

The Monitor Sticky Note Analogy

Walking across the room to check a giant 1,000-page book for every single phone number slows you down heavily (Double-Trip Memory Penalty).

Hanging a small sticky note right next to your telephone cache handles repeated lookups instantly (TLB Hit). You only take the slow walk if the name is missing (TLB Miss).

🔍 Hardware Caches03 / 04

The Translation Lookaside Buffer

Paging hits the system with a 50% speed tax by requiring two separate trips to main memory layout lines for every single instruction step.

Integrating an associative **Translation Lookaside Buffer (TLB)** directly into the CPU chip silicon caches recent address translations to bypass main RAM lookups entirely.

🛠️ EAT Math04 / 04

Effective Access Time (EAT) Formulations

Computing execution metrics under 90% Hit Rate, 100ns RAM Latency, and 1ns Cache Lookup overhead:

EAT = (Hit Rate * [TLB + RAM]) + (Miss Rate * [TLB + 2*RAM]) EAT = (0.90 * [1ns + 100ns]) + (0.10 * [1ns + 100ns + 100ns]) EAT = (0.90 * 101ns) + (0.10 * 201ns) Result = 90.9ns + 20.1ns = 111.0ns (Huge reduction from unaccelerated 200ns!)
