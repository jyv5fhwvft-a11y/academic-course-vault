Module 2: Process Management // Lecture 5

Lecture 05: Process Anatomy & The PCB Ledger

🎯 1. Objective

Diagram the internal memory layout of a process and define every tracking metric stored inside the Process Control Block (PCB) kernel ledger.

🛑 2. Prerequisites

Module 1 (All Lectures), C memory layout concepts (Stack vs. Heap).

🎪 3. Analogy 1 (Everyday Life): The Business Corporate Accountant

Imagine a massive corporate office building where multiple completely different businesses (User Processes) share the same workspace. Each business thinks it is the only company there. To keep them organized, the building manager has a dedicated filing cabinet containing a thick ledger folder for every single business. This folder is the Process Control Block (PCB). Inside it, the manager writes down exactly how much money the business has (Registers), which office doors they have keys to (File Descriptors), and exactly what line of their contract they are currently reading (Program Counter). If a business leaves the room, the accountant reads this ledger to restore their exact state when they return.

💻 4. Analogy 2 (Pure Technical): Container State Snapshot

A process layout matches a sandboxed virtual container, where the underlying host kernel preserves a structured C struct (struct task_struct in Linux) to cache metadata boundaries that hardware registers must shift into during a context switch.

🔗 5. System Cohesion Matrix

• Relies On: L02 (Dual-Mode Barrier) — Relies on Ring 0 privileges to protect the PCB arrays from being altered by unprivileged user application code.
• Feeds Into: L06 (Execution Mechanics) — Modifying, cloning, or discarding a process lifecycle requires allocating or freeing a physical PCB block struct inside the kernel slab allocator.

🔍 6. Core Breakdown

A process is a program in execution. It consists of more than just static machine code; it encompasses an active address space split into distinct regions: the Text Segment (compiled machine instructions), the Data Segment (global variables), the Heap (dynamically allocated memory), and the Stack (local variables and function parameters).

🛠️ 8. Practical Example

struct ProcessControlBlock { int pid; enum { READY, RUNNING, BLOCKED } state; unsigned long program_counter; unsigned long registers[16]; int open_files_map[256]; };

🎯 9. Interactive Classroom Activity

The Human PCB Blueprint Map: Draw a massive empty process memory map (Text, Data, Heap, Stack) on the classroom chalkboard. Hand four different students cards labeled "Global Int Variable," "Compiled Printf Instruction," "Malloc Address Pointer," and "Local Function Loop Index." Have them stand in the exact zone where their asset belongs.
