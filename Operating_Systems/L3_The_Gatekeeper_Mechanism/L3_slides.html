The Bank Teller Counter Analogy

You cannot simply walk past security guards and pull gold bricks directly out of a vault. You must step up to a bulletproof window (The Syscall Interface), write down your target operation code on a ticket (The Register Key), and hand it over.

The teller (Kernel Interrupt Table Router) verifies your ID permissions, manipulates the raw machinery on your behalf, and passes back your data.

🔍 Interrupt Vectors03 / 04

The Assembly Level Interface

When software calls a system task, it loads input parameters into standard processor hardware registers (rdi, rsi, rdx) and drops the core command identifier index key into the rax tracking slot.

Firing the assembly syscall command toggles the silicon status bit to Ring 0 and jumps execution to the **Interrupt Vector Table (IVT)** mapping array.
