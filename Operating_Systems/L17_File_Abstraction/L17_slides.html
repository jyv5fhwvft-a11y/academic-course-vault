🎪 Nested Boxes02 / 04

The Nested Treasure Chest Analogy

A file path like /home/user/resume.pdf is not a singular physical address; it is a nested set of instruction keys.

The root / is the master chest. Open it, read the directory file list, and find a pointer to the home box. Open home to find a link to user. A directory is simply a specialized map folder connecting strings to index keys.

🔍 Path Parsing03 / 04

Links and Directory Architecture

How structural shortcuts map across the file system tree geometry:

• Hard Link: An additional string entry name inside a directory pointing straight to an existing, shared historical Inode block.

• Soft (Symbolic) Link: A standalone text file holding an absolute string path redirecting down to an entirely separate node destination completely.

🛠️ Path Walk04 / 04

Trace Stream Path Resolution Walkthrough

Tracing VFS resolution steps when a system runs cat /var/log/sys.log:

Step 1: Fetch Inode #2 (Hardcoded Root directory block location). Step 2: Parse Inode #2 text contents. Locate row "var" -> Points to Inode #45. Step 3: Parse Inode #45 folder text data. Locate row "log" -> Points to Inode #812. Step 4: Parse Inode #812 index entries. Locate row "sys.log" -> Lands on final target file Inode #9042, unlocking block byte streams.
