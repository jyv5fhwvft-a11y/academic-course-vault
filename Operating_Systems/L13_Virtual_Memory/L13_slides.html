🔍 Eviction Routines03 / 04

Demand Paging & Fault Interrupts

The hardware MMU reads a Present/Absent bit inside the active entry pointer line. If marked absent, the CPU traps execution with a page fault interrupt.

If no hardware frames are vacant, page replacement algorithms like **FIFO** (First-In, First-Out) or **LRU** (Least Recently Used) pull down a victim page block.

🛠️ Eviction Trace04 / 04

Trace Stream Eviction Behavior Matrix

Tracing access allocations string 1, 2, 3, 4, 1, 2 over a 3-frame RAM cache footprint:

FIFO Trace: - 1, 2, 3 load contiguously (3 faults) - 4 evicts oldest 1 (4 faults) -> 1 evicts next oldest 2 (5 faults) -> 2 evicts 3 (6 faults) LRU Trace: - 1, 2, 3 load contiguously (3 faults) - 4 evicts least-recently used 1 (4 faults) -> 1 evicts 2 (5 faults) -> 2 evicts 3 (6 faults) Result: Both strategies pay an identical 6-fault penalty for this access trace.
