Lecture 13: Virtual Memory, Demand Paging & Page Replacement Summary

1. Objective

Trace a page reference execution string manually through FIFO and LRU page replacement pipelines, and accurately log final Page Fault counts.

2. Prerequisites

L11, L12, basic logic queues.

3 & 4. Pedagogical Analogies

Analogy 1 (Everyday Life): The Limited Desk and the Library Storage Stacks
Imagine you are studying in a massive university library. Your study desk can only fit exactly 3 books at a time (Physical Frame Allocation). You are currently writing an essay that references 10 different books (Virtual Address Space). You start working; you look for Book A on your desk. It isn't there! This is a Page Fault. You must pause your work, wait for a runner to fetch Book A from the deep basement storage stacks (The Hard Disk/Swap Space), and drop it onto your desk. When your desk fills up completely and you need a 4th book, you must choose one current book to throw off your desk and send back to the basement stacks (Page Replacement Policy).

Analogy 2 (Pure Technical): An On-Demand Network Streaming Video Buffer
Demand paging matches media streaming platforms that load only the immediate 10 seconds of a massive 4K movie file into active memory, swapping old data blocks clear out of local cache boundaries when the player scrubs to a new section.

5. System Cohesion Matrix

• Feeds Into: Module 4 (Process Synchronization) — Because virtual memory allows multiple concurrent threads to securely share specific page entries, it sets the stage for race condition contentions.
• Feeds Into: Module 5 (File & Storage Management) — Swapping unmapped dirty pages out of RAM requires directly orchestrating raw block writes to disk storage partitions.

6. Core Breakdown

Demand Paging allows an operating system to execute an application even if its total memory footprint is vastly larger than the computer's physical RAM chip. The kernel leverages a Present/Absent Bit inside each page table entry. If a thread attempts to access a virtual page marked as absent, the hardware MMU cannot translate it and triggers a specialized Page Fault Exception Interrupt.

The kernel intercepts this fault, halts the thread, locates the missing block inside the disk Swap Space, copies the page into an empty physical frame, updates the page table bit, and rewinds the CPU to retry the instruction. If no physical frames are vacant, a replacement algorithm—such as FIFO (First-In, First-Out) or LRU (Least Recently Used)—is invoked to evict a page.

7. Lexicon / Terms

• Demand Paging: An optimization mechanism where virtual pages are loaded into physical RAM strictly on-demand only when an active instruction requests them.
• Page Fault: A valid hardware exception interrupt triggered when a thread attempts an operation on a page marked as absent from physical RAM.
• Swap Space: A designated raw block sector layout on a hard drive or SSD used to cache evicted virtual page overflows.
• Thrashing: A critical system failure state where a machine spends more time continuously swapping blocks back and forth to disk than executing actual instruction paths.

8. Practical Example: Reference String Analysis Matrix

Workload Vector Constraints: 3 physical frames allocated, Reference String: 1, 2, 3, 4, 1, 2

------------------------------------------------================= 1. FIFO (First-In, First-Out) Execution Trace: - Access 1, 2, 3 -> Loads contiguously into RAM -> 3 Page Faults - Access 4 -> Evicts oldest page (1) -> Frames: [4, 2, 3] (Fault 4) - Access 1 -> Evicts next oldest (2) -> Frames: [4, 1, 3] (Fault 5) - Access 2 -> Evicts next oldest (3) -> Frames: [4, 1, 2] (Fault 6) Total FIFO Faults = 6 2. LRU (Least Recently Used) Execution Trace: - Access 1, 2, 3 -> Loads contiguously into RAM -> 3 Page Faults - Access 4 -> Evicts least used (1) -> Frames: [4, 2, 3] (Fault 4) - Access 1 -> Evicts least used (2) -> Frames: [4, 1, 3] (Fault 5) - Access 2 -> Evicts least used (3) -> Frames: [4, 1, 2] (Fault 6) Total LRU Faults = 6 ------------------------------------------------=================

9. Interactive Classroom Activity

The Human Reference String LRU Simulation: Line up three empty chairs at the front of the room to serve as a 3-frame RAM block. Call out numbers from a string. Have students carrying matching numeric cards rush up to sit in an empty chair. When a student arrives and all chairs are full, instruct the class to evaluate who has been sitting in their chair the longest without being touched, and make that student vacate their seat back to the lobby.
