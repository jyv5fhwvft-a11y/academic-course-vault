🎪 Room Illusions02 / 04

The Hotel Room Mapping Analogy

Every tenant checking in receives a card key programmed for "Room 100" (The Logical Address). However, the central front desk hardware (The OS) silently relocates each user to a physical slot location.

Tenant A starts at real address 500 (Base = 500) and only owns clearance for a small 10-room layout (Bound = 10). Accessing address 115 fires an immediate access error.

🔍 Hardware Protection03 / 04

Dynamic Hardware Relocation

The compiler compiles code starting from virtual zero lines. At runtime, the hardware chip intercepts every pointer access: Physical = Logical + Base.

If a logical access falls below 0 or hits the assigned Bound Register ceiling, the CPU stops instruction streaming instantly to shield companion memory segments.
