Lecture 10: Relocation Models & Base-and-Bound Isolation

🎯 1. Objective

Manually derive valid physical memory address locations from logical addresses given specific Base and Bound hardware register limits, and catch security bounds exceptions.

🛑 2. Prerequisites

Module 2 (All Lectures), hardware registers.

🎪 3 & 4. Pedagogical Analogies

Analogy 1 (Everyday Life): The Hotel Room Numbering Illusion

Imagine a large hotel resort. Every single guest checking in receives an automated room booklet that says they are staying in "Room 100" (The Logical Address). When they go to find their room, they must use a master keycard lock. The hotel's physical architecture silently maps each guest's "Room 100" to a completely different floor. For Guest A, the room starts at real room 500 (Base Register = 500) and they only paid for a small 10-room suite (Bound Register = 10). If Guest A tries to open "Room 115", their keycard fails because it exceeds their bound boundary. Guest B's "Room 100" starts at real room 800. They both think they occupy address 100, but the front desk (The OS) relocates them seamlessly.

Analogy 2 (Pure Technical): An Offset Array Pointer Index

Base-and-bound protection behaves identically to a safe compiler runtime wrapper around a raw byte array pointer. The Base register functions as the absolute starting array memory address (&array[0]), while the Bound register acts as a strict if (index >= length) array bounds check.

🔗 5. System Cohesion Matrix

Relies On: L02 (Dual-Mode Barrier) — Relies on Ring 0 privileges to lock the physical Base and Bound registers so user threads cannot change their own memory space walls.

Feeds Into: L11 (The Paging Model) — Serves as the historical precursor that proves contiguous variable-sized memory allocations lead to severe external fragmentation, driving the invention of fixed-size paging.

🔍 6. Core Breakdown

To achieve multiprocessing, memory must be virtualized. The earliest model used Dynamic Relocation via hardware registers. When a program is loaded into RAM, the kernel notes its physical starting location into a hardware Base Register and its maximum allowable block size into a Bound Register.

The CPU uses these to evaluate every instruction at runtime: Physical Address = Logical Address + Base. If the logical address is less than zero or greater than or equal to the Bound register, the hardware interrupts execution instantly and throws a segmentation fault trap.

🏷️ 7. Lexicon / Terms

  • Logical Address A virtual address generated by the compiler and CPU instruction stream during development and runtime execution.
  • Physical Address The actual, hardware-wired slot location inside the physical RAM chip matrix.
  • Base Register A physical CPU tracking chip that stores the absolute starting physical address of a program's active memory slot.
  • Bound Register A physical hardware safety register tracking the maximum size allocation block granted to a running process context.

🛠️ 8. Practical Example Mathematical Problems

Hardware Environment Setup: Base = 14000 and Bound = 2000

------------------------------------------------================= Scenario A: CPU attempts to fetch instruction from Logical Address 450. 1. Validation: 450 < 2000 (Passes Bound check verification) 2. Translation: Physical Address = 450 + 14000 = 14450 Result: SAFE / VALID EXECUTION Scenario B: CPU attempts memory operation on Logical Address 2100. 1. Validation: 2100 >= 2000 (EXCEEDS ALLOWABLE BOUND CEILING!) Result: HARDWARE EXCEPTION TRAP / SEGMENTATION FAULT FAULT PANIC ------------------------------------------------=================

🎯 9. Interactive Classroom Activity

The Chalkboard Relocation Machine: Draw a grid of numbers 0 to 100 on the board to represent physical RAM. Hand two students dry-erase markers. Assign Student 1 a Base of 20 and a Bound of 10. Assign Student 2 a Base of 50 and a Bound of 15.

Shout out logical addresses like "Student 1, modify location 5!" or "Student 2, access location 20!" Have the class audit if the student writes on the correct physical grid square or if they must freeze and yell "Segmentation Fault!"
