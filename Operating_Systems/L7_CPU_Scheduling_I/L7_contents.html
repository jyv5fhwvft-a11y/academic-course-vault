Lecture 07: CPU Scheduling I (Non-Preemptive vs. Preemptive Foundations)

🎯 1. Objective

Manually compute turn-around time, response time, and average wait metrics for a given array of task vectors under FCFS, SJF, and Round Robin scheduling algorithms.

🛑 2. Prerequisites

L05, L06, basic arithmetic.

🎪 3 & 4. Pedagogical Analogies

Analogy 1 (Everyday Life): The Grocery Store Checkout Line

Imagine a grocery store checkout lane with one single cashier (The CPU Core). First-Come-First-Served (FCFS) means checking people out based on when they joined the line; if a person with a massive cart full of items stands in front, a person buying a single pack of gum is trapped waiting forever (Convoy Effect). Shortest-Job-First (SJF) means sorting the line so the person with the single pack of gum goes first; this minimizes average wait times, but requires magically predicting how long someone will take to pay. Round Robin (RR) means the cashier spends exactly 30 seconds processing a customer's items, and if they aren't done, they are forced to walk to the very back of the line to wait for their next timed turn (Time Quantum fairness).

Analogy 2 (Pure Technical): Network Packet Routing Ring Buffers

Scheduling policies match algorithmic traffic-shaping configurations inside local area network routers, sorting whether data frame chunks are dispatched via sequential queues, size metric predictions, or strict time-sliced round-robin rotations.

🔍 6. Core Breakdown

• The Scheduling Domain: The CPU scheduler decides which process in the READY state gets to slide onto an active processor core next.

• FCFS (First-Come, First-Served): Non-preemptive and algorithmically trivial but suffers from severe performance degradation under the Convoy Effect (short tasks trapped behind long execution workloads).

• SJF (Shortest Job First): Minimizes average wait times mathematically but introduces starvation risks for large processes if small, rapid tasks constantly arrive in the queue.

• Round Robin (RR): Introduces time-slice preemption using a Time Quantum. If the quantum is configured too large, Round Robin degrades into simple FCFS; if configured too small, the system burns excessive CPU cycles on context-switching overhead instead of real program execution.

🏷️ 7. Lexicon / Terms

  • Preemption The ability of an operating system to forcefully pause a running process to hand the CPU core to a different task.
  • Time Quantum The maximum continuous block of time a thread is permitted to run under a preemptive scheduling policy before being context-switched.
  • Convoy Effect A system slowdown scenario where short processes wait a prolonged duration for a long, heavy process to vacate the CPU core.
  • Average Wait Time The arithmetic mean of the total time processes spent sitting inside the READY queue waiting for execution access.

🛠️ 8. Practical Example Matrix

Gantt Chart Derivation Exercise: Given three processes arriving at time 0: P1 (Burst = 24), P2 (Burst = 3), P3 (Burst = 3).

------------------------------------------------================= 1. FCFS Scheduling Policy (Order: P1 -> P2 -> P3) Wait Times: P1 = 0ms, P2 = 24ms, P3 = 27ms Average Wait Time: (0 + 24 + 27) / 3 = 17.0ms 2. SJF Scheduling Policy (Order: P2 -> P3 -> P1) Wait Times: P2 = 0ms, P3 = 3ms, P1 = 6ms Average Wait Time: (0 + 3 + 6) / 3 = 3.0ms ------------------------------------------------=================

This problem highlights the radical optimization efficiency achieved by prioritizing shortest-job metrics over insertion-order queues.

🎯 9. Interactive Classroom Activity

The Physical Checkout Lane Simulation: Line up five students at the front of the classroom. Assign them slips of paper detailing a technical task complexity weight (e.g., writing 2 sentences vs. writing 10 sentences on the board).

Run the line live using FCFS first, then sort them by SJF, and finally run them with a 15-second Round Robin timer to physically map out how waiting metrics fluctuate for the students.
