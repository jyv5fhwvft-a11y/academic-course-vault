🎯 2. Core Curriculum Blueprint (7 Pillars)

  • P1
    Monolithic vs. Microkernel Design: Privilege borders, modular code boundaries, and kernel task isolation mechanisms.
  • P2
    Traps & Protection Barriers: Intercepting system calls safely via the hardware Interrupt Descriptor Table (IDT).
  • P3
    Concurrency & Synchronization: Defending critical sections with atomic locks and thread mutex queues.
  • P4
    Address Translation Mechanics: Page frame tables, high-speed on-chip TLB caching, and hardware MMU steps.
  • P5
    Virtual Memory & Page Faults: Managing demand paging loops, LRU evictions, and storage disk swap partitions.
  • P6
    Virtual File Systems (VFS): Directory topology mapping, parsing file descriptors, and decoding ext4 inode byte offsets.
  • P7
    Drivers & Network Security: Programmable Interrupt Controllers (PIC IRQ), device driver file tables, and stateful firewalls.

📜 5. Strict Academic Integrity Rules

Code Leak Protection: All memory allocations (malloc) must be explicitly verified and reclaimed (free). Memory boundary leaks observed on automated system infrastructure compilation checks yield a zero score flag for the attempt.

Collaboration Policy: Students are strongly encouraged to discuss core execution structures using conceptual human analogies, but all machine register paths and low-level assembly lines must be completely independently compiled inside your personal workspace arrays.
