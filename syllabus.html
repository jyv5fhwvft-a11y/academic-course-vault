🎯 2. Core Curriculum Outline (7 Modular Pillars)

  • M1
    Module 1: Introduction & OS Architectures
    Lectures 00 - 01. Explores resource multiplexing, hardware timescale divisions, monolithic kernels, and isolated user-space sandboxes.
  • M2
    Module 2: Memory Management — Paging & Translation
    Lectures 02 - 05. Covers virtual-to-physical address translation maps, hardware MMU tracking, on-chip associative TLB caching, and demand paging page fault exceptions.
  • M3
    Module 3: Process Management — Control Trees & Lifecycles
    Lectures 06 - 08. Traces the parent-child task control blocks, fork() system duplication primitives, execution context scheduling queues, and hardware copy-on-write (COW) memory maps.
  • M4
    Module 4: Concurrency & Synchronization Primitives
    Lectures 09 - 14. Examines shared critical sections, memory race conditions, atomic hardware test-and-set loops, deadlocks, and condition signaling waitchannels.
  • M5
    Module 5: Storage Architectures & File Systems
    Lectures 15 - 19. Investigates the Virtual File System (VFS), directory entry (dentry) graph caches, ext4 inode block allocation pointers, crash consistency metrics, and journaling logs.
  • M6
    Module 6: Device Drivers & Hardware Communication
    Lectures 20 - 21. Details programmed I/O status bit polling, programmable interrupt controllers (PIC IRQ pin gates), and driver file operation tables inside Ring 0.
  • M7
    Module 7: Operating System Security Matrix
    Lectures 22 - 28. Validates user permission capability bitmasks, call stack buffer overflow mitigations, cryptographic password salting, and stateful netfilter firewalls.

📜 5. Strict Academic Integrity Rules

Code Leak Protection: All memory allocations (malloc) must be explicitly verified and reclaimed (free). Memory boundary leaks observed on automated system infrastructure compilation checks yield a zero score flag for the attempt.

Collaboration Policy: Students are strongly encouraged to discuss core execution structures using conceptual human analogies, but all machine register paths and low-level assembly lines must be completely independently compiled inside your personal workspace arrays.
